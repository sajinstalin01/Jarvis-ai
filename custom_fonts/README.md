# JARVIS custom fonts

This folder is the local font collection used by the Appearance → Font collection menu.

- Import a font in the app, or copy a licensed `.ttf`, `.otf`, or `.ttc` file into this folder and choose **Refresh** in the font manager.
- JARVIS registers valid fonts at startup. Your chosen family is saved in `config/ui_settings.json`.
- Font binaries are intentionally excluded from Git so your personal fonts, large files, or fonts with restrictive licences are not uploaded by accident.
- Only install fonts you are allowed to use. Importing a font copies it here; it does not install it system-wide.
